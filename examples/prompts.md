# 範例提問

可搭配 README 安裝的 0.1.1 server。此版只有 samples，正式資料仍待匯入；以下提問會得到示範警示或查無符合紀錄。

## 1. 先確認資料狀態

> 請先呼叫 get_data_status，說明 CDC、NHI、TFDA 目前各自使用正式資料還是 sample。列出資料來源、版本、更新時間及涵蓋範圍；未提供的欄位明示未知，不要猜測。

## 2. CDC 採檢送驗

> 請使用 Taiwan Laboratory MCP 查詢麻疹的採檢送驗要求。依檢驗方法及檢體分列採檢時機、容器、保存和運送條件，保留例外，附官方網址、手冊版本與頁碼。若是 sample，請明示不能用於實際採檢。

## 3. NHI 檢驗支付

> 請查 HbA1c 相關健保檢驗項目，列出代碼、中英文名稱、支付點數、生效起迄與備註。保留多筆相關結果，附來源及更新時間；不要把點數換算成新臺幣或推定個案給付資格。

## 4. TFDA IVD 許可證

> 請查 HPV DNA 相關 IVD 許可證，列出許可證字號、品名、效能、申請商、製造商、有效日期與註銷資訊。說明目前資料涵蓋範圍並附來源；沒有完整證據時標示未能確認有效狀態。

## 5. 練習查無結果

> 請查 SAMPLE-NO-MATCH-123。若查無符合項目，告訴我查過哪個資料集及版本，不要據此判定該產品不存在，也不要以相似產品資料代替。
