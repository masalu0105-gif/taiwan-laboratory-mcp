這些日常的痛，用問的就好

你不用先知道正確答案長什麼樣。用模糊的說法問，AI 自己去比對，再把出處攤給你看。

01 · 法規／採購

食藥署許可證，一個字打錯就找不到

在食藥署查詢頁猜正式品名、輸驗證碼、一次只看一筆

用模糊說法問，AI 比對品名跟效能，幫你鎖定最相關的幾張證。

「HPV 的檢測試劑，有哪幾家有證？」
02 · 檢驗室

特殊檢體不知道怎麼送

翻疾管署採檢手冊翻半天

檢體、容器、保存、運送條件一次給你，附手冊版本與頁碼。

「疑似麻疹的檢體怎麼採、怎麼送？」
03 · 檢驗室

院內做不了，要送哪一家

在認可機構名冊裡逐家比對範圍

直接問哪些認可檢驗機構能做這個項目，名單跟範圍一起列出。

「登革熱 PCR 可以送哪些認可實驗室？」
04 · 申報

要報哪個健保碼、幾點

翻健保署那包支付標準檔案

某個項目或方法對應的代碼、點數與支付規範，直接問。

「HbA1c 有哪些健保碼、支付幾點？」
05 · 法規

業務拿來的許可證要確認

一張一張回食藥署查

證號查真偽、看在誰名下、有沒有註銷或快到期。

「衛部醫器輸字第 0XXXXX 號還有效嗎？」
06 · 法規

自家證的效期盤點

從內部清單一筆一筆核對

列出公司名下全部許可證，依效期排序，抓出半年內要展延的。

「XX 公司名下有哪些證，哪些一年內到期？」

推薦

貼一個網址，什麼都不用裝

把上面那個網址貼進 AI 的 MCP 設定，存檔重開就能問。上課發給學生、在別人電腦上臨時示範，都用這個。

裝在自己電腦

要離線查，或想自己決定用哪一版資料，選這個。程式一行裝好，四份正式資料另外用一鍵腳本下載，大約 300 MB。

{

    "taiwan-laboratory": {
      "url": "https://lab.masalulab.com/mcp"
    }
  }
}
